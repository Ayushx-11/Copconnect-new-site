# CopConnect — New Site

A refreshed, modern landing page for **CopConnect**, India's most human-centred cyber safety movement. Built with vanilla HTML/CSS/JS — no build step required.

## Tech

- Plain HTML5 / CSS3 / vanilla JS
- Nunito + Nunito Sans + Instrument Serif from Google Fonts
- SVG mascot illustrations (no external assets)
- Bento-grid layouts, glassmorphic nav, animated stat counters, scroll reveal, marquee, rotating CopBot tips

## Run locally

Just open `index.html` in a browser, or:

```bash
npx serve .
# or
python -m http.server 3000
```

## Deploy

Configured for Vercel via `vercel.json`. Push to GitHub and import, or run `vercel` in this folder.

## Design notes

- **Colors:** Orange `#E8652A` primary, cream `#F5EFE6` background, ink `#1A1209` text, blue `#2563EB` mascot accent.
- **Sections:** Hero + bento mascot card · About bento · Platform with feature grid + portal · Learning hub · CCIO program · Tips · Family block · Merch · Sessions form · Final CTA · Footer.
- **Accessibility:** Reduced-motion respected, focus rings, semantic landmarks, sufficient contrast.
